## Downloaded on First Use (Not Redistributed)

The container image and repository do **not** redistribute model checkpoints, forcing datasets, initial conditions, or unlicenced third-party model repositories:

- **`ArchesClimate-SSP`** (`https://github.com/grahamclyne/ArchesClimate-SSP`, commit `06ce82dca2414db4f1b3d6940b61c5cd723f4620`): upstream repository carries no licence file (all rights reserved by its authors). Its source archive is **not** baked into the container image or repository; instead, `aimip setup` / `aimip fetch -m archesclimate-ssp` (or `aimip run -m archesclimate-ssp` on first use) downloads the pinned source archive directly from GitHub into `$AIMIP_DATA/code/ArchesClimate-SSP` and verifies its SHA-256 / extracted tree digest before execution.
- **`monthly-diffusion` (`md-1.5`)** (`https://github.com/kjhall01/monthly-diffusion`, commit `b077d3bcbf602a6b363d5a9da28cf1dc3583c4fb`, tag `MDv0.9-1.5-licensed`, Zenodo `10.5281/zenodo.21430292`, MIT License, Copyright (c) 2026 Kyle Hall): downloaded on first use into `$AIMIP_DATA/code/monthly-diffusion` and `$AIMIP_DATA/models/md-1.5/`, with both the archive SHA-256 and the 37-file extracted tree SHA-256 verified before import, and `config.pkl` / `weights.pt` verified on `O_NOFOLLOW` descriptors before restricted deserialization.
- **`miles-credit` / `CAMulator` (`camulator`)** (`https://github.com/WillyChap/miles-credit`, commit `d0eb9add439f09bd25883f4393296f3266b5876d`, fork of `NCAR/miles-credit`; weights & inputs at `https://huggingface.co/willychap/camulator`, revision `01afc272553fedd7e21d8046149ec41d2a5d90b8`, Apache-2.0): downloaded from the pinned commit archive (`be2a070c...`, 380 regular files, `LC_ALL=C` `find -type f` tree SHA-256 `c560d3bf...`, with the 14 in-tree `credit/applications/*.py -> ../../applications/*.py` relative symlinks verified in-tree and omitted on extraction) into `$AIMIP_DATA/code/miles-credit-camulator` (and, when `--with-camulator` is passed to `install/install-native.sh`, staged non-packaged under `$PREFIX/venv-camulator/src/miles-credit` and exposed on `sys.path` via `miles_credit_camulator.pth` because upstream `pyproject.toml` `[tool.setuptools] packages` omits subpackages/namespace directories such as `credit.transforms.deprecated` and `credit.preblock`), with `checkpoint.pt00069.pt` and all `.pth` initial-state tensors verified by SHA-256 on `O_NOFOLLOW` descriptors before `torch.load(..., weights_only=True)`.
- **`cBottle-3d` (`cbottle-3d`)** (weights at `https://huggingface.co/nvidia/cbottle`, revision `e60ce82b236b953d79d3ead7f43445a3bb8e37d3`, Apache-2.0; conditioning SST `amip_midmonth_sst.nc` from PCMDI-AMIP-1-1-9 prepared for input4MIPs, CC-BY-4.0): downloaded on first use into `$AIMIP_DATA/models/cbottle-3d/`, with each `.checkpoint` ZIP archive verified by SHA-256 on an `O_NOFOLLOW` descriptor and its `net_state.pth` verified via `torch.load(..., weights_only=True)` before loading.
- **`spherical-dyffusion` (`spherical-dyffusion`)** (`https://github.com/Rose-STL-Lab/spherical-dyffusion`, commit `a10b3e7f1ae529193537a128c86b531adb45f23b`, Apache-2.0; weights at `https://huggingface.co/salv47/spherical-dyffusion`, revision `56fcb5d995717e91ba770f5ee41e8c3a8cfb00f6`, Apache-2.0; 1° FV3GFS reference data at Zenodo `10.5281/zenodo.10791087`, CC-BY-4.0): downloaded on first use into `$AIMIP_DATA/code/spherical-dyffusion`, `$AIMIP_DATA/models/spherical-dyffusion/`, and `$AIMIP_DATA/inputs/spherical-dyffusion/fv3gfs-2021/`, with the 190-file extracted tree SHA-256 verified before execution and both `.ckpt` checkpoints verified on `O_NOFOLLOW` descriptors before deserialization via a restricted `pickle_module` whose `Unpickler.find_class` allows only the verified checkpoint globals. Inside `venv-sdyff` (`install-native.sh --with-sdyff`), `apex FusedLayerNorm` is replaced by `torch.nn.LayerNorm` (numerically equivalent up to float rounding) via a local `apex.normalization` shim solely to satisfy `ai2cm/modulus@94f62e1c` `modulus.models.sfno.sfnonet`'s unguarded top-level import; both `modulus` and `spherical-dyffusion` `sfnonet` already instantiate `torch.nn.LayerNorm` for `normalization_layer='layer_norm'`, and the published checkpoints configure `normalization_layer='instance_norm'` (`torch.nn.InstanceNorm2d`).
- **Model checkpoints, initial conditions, and forcing datasets**: downloaded directly by the user from Hugging Face Hub, Zenodo (including `10.5281/zenodo.17065758`, `10.5281/zenodo.10791087`, and `10.5281/zenodo.22795233`, CC-BY-4.0), Open Storage Network (`s3://m2lines-pubs/Samudra`, MIT), and Google Cloud (`ARCO-ERA5`), or supplied/staged by the user (e.g. monthly-mean ERA5 initial states for `md-1.5` from the Copernicus/ECMWF Climate Data Store, CC-BY-4.0 since 2025-07-02), into `$AIMIP_DATA` and verified against `src/aimip/aimip.lock` under each upstream dataset or model author's terms. The ArchesWeather / ArchesWeatherGen checkpoints, initial state, forcing and statistics come from Zenodo record 22795233 ("ArchesWeather AIMIP data", CC-BY-4.0); `aimip fetch` extracts the checkpoints and their configurations unchanged from its `model_checkpoints.zip`.
